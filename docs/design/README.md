## Decisões vigentes

- Marca **contemporânea cultural**, com leitura institucional.
- Paleta **A — Território**: argila, verde-profundo e ouro velho.
- Tema **claro é o padrão**; escuro é escolha explícita.
- Logo precisa funcionar ao lado de funders e em impressão.
- HEALTH é extensão futura; não há tela de saúde no MVP.
